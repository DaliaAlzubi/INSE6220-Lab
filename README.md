# INSE 6220 (Advanced Statistical Approaches to Quality) Lab Winter 2023

This repository contains course materials, tutorials, Jupyter notebooks, datasets, and practical examples for INSE 6220.

## Topics

- Descriptive and inferential statistics
- Probability distributions
- Hypothesis testing
- Regression and ANOVA
- Logistic regression
- PCA and dimensionality reduction
- Classification and clustering
- Model training and evaluation
- Statistical machine learning

## Materials

The repository includes:
- Jupyter notebooks and tutorials
- Sample projects
- Datasets
- Google Colab guide
- Statistical and machine learning examples
